### Fix before ratifying (Surfaced by the Iverson advisory; verified by CoS)

- **HUB.md Worktrees bullet conflicts with point 10 and outranks it** (Codex Blocker / Claude Improvement). `factory/HUB.md:21` still says "Never remove … unknown ignored data, browser profiles or evidence". `factory/RESET-PLAN.md:111-112` supersedes only D8's clause, and (b) at `RESET-PLAN.md:117-121` allows unknown ignored data to be copied and the tree removed. `HUB.md:3` lists authority as "root CLAUDE.md, this file, RESET-PLAN.md", so a faithful reader keeps HUB and point 10 does nothing for any tree holding `.factory-local/`. - **(a) is all-or-nothing on mixed trees** (Claude Blocker / Codex Improvement). Under `RESET-PLAN.md:113-114`, content is rebuildable only "iff every ignored path lies under" the three cache directories. The proposal counts `.factory-local/` in 161 of 176 records (`D8-RETENTION.md:55-56`), so almost every tree is mixed. Read as written, a mixed tree either gets no cache cleanup (Codex) or has its `node_modules` pulled into (b) "every other ignored path" and copied into permanent evidence (Claude). Both readings defeat the row's purpose. Classify each path instead: cache dirs are rebuildable in any eligible tree, and everything else is evidence.
- **(d) leaves out KEEP_NESTED_PARENT** (Claude Blocker / Codex Improvement). (d) at `RESET-PLAN.md:128-129` lists canonical, KEEP_DIRTY, KEEP_OPEN_PR, KEEP_IN_FLIGHT, KEEP_LOCKED, KEEP_PROCESS_REF and KEEP_FOREIGN_PATH. The census emits KEEP_NESTED_PARENT (`factory/worktree-census.mjs:13-14`, `:121`), and (a)'s "any KEEP class" (`RESET-PLAN.md:116`) covers only rebuildable deletion. I reproduced the harm with git locally: a nested worktree under an ignored `.factory-local/`, followed by `git worktree remove` on the parent (no `--force`), exits 0. It deletes the nested checkout and leaves its registration `prunable`. Name KEEP_NESTED_PARENT (and KEEP_MAIN), or require the recomputed census bucket to be REMOVE_AFTER_EVIDENCE/REMOVE_CANDIDATE.
- **(e) growth cap contradicts (a)/(c)** (Codex Blocker / Claude Improvement). (e) at `RESET-PLAN.md:132-133` allows deleting rebuildable content once the "verdict or gate record is written", with no eligibility, KEEP or live-process condition. (a) at `RESET-PLAN.md:115-116` limits rebuildable deletion to (c)-eligible trees with "any KEEP class … never touched". I ran `git check-ignore` against the tip's `.gitignore` + `adversarialllm/.gitignore`: `adversarialllm/evidence/worktree-retention/**` is **not ignored**, so copies show up as committable untracked files, and once committed, §1.3 (`RESET-PLAN.md:228`) forbids removing them. Name the receiving checkout, collision handling, and whether the copy is committed or kept in an ignored local store. This is the proposal's review note 3 (`D8-RETENTION.md:88-90`).
