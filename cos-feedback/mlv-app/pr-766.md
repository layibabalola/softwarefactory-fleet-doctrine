## Open introduced blocker: script suffix mistaken for host -File

`Get-FixtureMatch` identifies PowerShell by executable name, then considers any token whose immediate predecessor is `-File`/`-f` a path. It has no state recording that `-Command` or an encoded-command option already began script text. Thus the published input `pwsh -NoProfile -Command "Start-Sleep 300; # ignored" -File <fixture>` admits the plain fixture path even though that suffix is command text. The census calls it `fixture`, and `Stop-FixtureLeftovers` fresh-queries the pinned process's own command line using the same predicate before Kill. Handle pinning protects identity against PID reuse; it cannot repair a false ownership predicate. The suite-end sweep reaches this path.

Sources: [matcher and census, lines 533–580](https://github.com/SuperDimensionalSpaceFortress/MLV-App/blob/0bbcfb97267c2630168a175c3a75a9b14563bcc7/tools/testing/test-ultra-magnus-agent-quiet-lease.ps1#L533-L580), [pinned stop and sweep, lines 587–613](https://github.com/SuperDimensionalSpaceFortress/MLV-App/blob/0bbcfb97267c2630168a175c3a75a9b14563bcc7/tools/testing/test-ultra-magnus-agent-quiet-lease.ps1#L587-L613), [suite-end invocation](https://github.com/SuperDimensionalSpaceFortress/MLV-App/blob/0bbcfb97267c2630168a175c3a75a9b14563bcc7/tools/testing/test-ultra-magnus-agent-quiet-lease.ps1#L4277-L4283).

Remedy scope: conservatively stop path admission after PowerShell command/encoded-command forms, including supported abbreviations/prefixes; never resume host-option parsing on a later `-File`. Regression should cover the exact producer input and variants through matcher, census and pinned sweep seams, proving unknown/non-kill and preserved numeric-zero versus unknown reporting. Preserve genuine `-File` fixture positives. Independent review must assess any successor; existing green tests do not discharge this counterexample.

Producer acknowledgment and proposed remedy are already explicit in [r5+r6 disclosure](https://github.com/SuperDimensionalSpaceFortress/MLV-App/pull/766#issuecomment-6705684341). [Same-head sol publication](https://github.com/SuperDimensionalSpaceFortress/MLV-App/pull/766#issuecomment-6706058972) says CHANGES_REQUESTED and reproduced blocker, but its quoted narrative is truncated after “With this command line:”.
