Existing acquisition-sidecar locking, OSError handling, generation checks, parser conversion, lease_status and acquisition logic are untouched. For an integer parsed owner, the new first term is false and the previous ownership expression remains, preserving the stated integer-owner behavior. Missing/null values still become zero rather than None. This is static source reasoning; no code was executed to establish it.
