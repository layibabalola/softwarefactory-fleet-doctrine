## SHOULD: validate the full persisted record before calling it already installed
Location:
https://github.com/layibabalola/agent-bridge/blob/8d7ebd6b523662afa7558f19c03c521011e8157f/agent_bridge/pack_cli.py#L157-L179
The reader checks schema_version, pack_id, project, version and sha, but never checks installed_at or installed_by. A five-key object with the matching identity and both provenance fields absent, or those fields set to arrays/null, is returned as successful already_installed and never repaired. This is a static, directly traceable gap relative to the seven-field record/malformed-record wording, not a role-authority bypass.
Remedy: validate required provenance fields and their expected types/shape, or explicitly define that existing-record validity is only identity validity and narrow the malformed-record claim. Preserve the never-rewrite behavior.
Regression: matching five-key object, missing each provenance field, wrong types, invalid timestamp; each should either reject without filesystem effects or be explicitly documented as permitted.
Classification: SHOULD / contract hardening. Not an independently demonstrated MUST.

## SHOULD: bound and type-check the existing-record read
Location:
https://github.com/layibabalola/agent-bridge/blob/8d7ebd6b523662afa7558f19c03c521011e8157f/agent_bridge/pack_cli.py#L142-L155
https://github.com/layibabalola/agent-bridge/blob/8d7ebd6b523662afa7558f19c03c521011e8157f/core/storage.py#L718-L724
The record is read wholly before any lock timeout applies. No byte bound or regular-file requirement exists. A very large local file can consume unbounded memory; on POSIX a FIFO at the exact record path can block on open/read before the 30-second lock budget. The current deep-JSON and huge-integer tests cover parse exceptions, not bounded reads. This requires local control/corruption of the state tree; it is not a demonstrated remote exploit and the public CI is Windows-only.
Remedy: reject nonregular records and impose a small documented record byte limit, ideally checked on the opened handle with bounded reading rather than a separate racy stat alone.
Regression: oversize record, permitted-platform nonregular record and bounded refusal with no mutation. No such test was run in this review.
Classification: SHOULD / resilience; POSIX FIFO consequence is conditional, not Windows CI proof.
