The match is regex, not a `Directory.GetFiles` search pattern (`GetFiles(auditDir)` at `:41695` has no pattern). `Regex.Escape` turns `*` into `\*`, and `.Replace("\\*", ".*")` makes that a wildcard, so the check for R841 becomes `^R.*841-haiku-compliance\.md$`. It also matches any name ending in the digits, e.g. `R900-retro-of-R841-haiku-compliance.md`. Short first tokens are worse: a commit whose first R-token is `R1` or `R41` is satisfied today by the existing `R840-R841-{haiku-compliance,implementation-audit,haiku-ux}.md` (CoS reproduced this with a .NET-equivalent regex against the tip's `.claude/audits/`). The gate can therefore false-PASS Haiku-tier code with no swarm for that R. Unblock: match whole R-number tokens, e.g. `^R(\d+-R)*{n}(-R\d+)*-haiku-compliance\.md$` (digit-bounded, paired prefix/suffix), or split the leading `R…-R…` run on `-R` and test exact numbers; add a fixture selftest pinning R1841 / R41 / `R841-R842-…` cases. *Surfaced by the Iverson advisory (Claude + Codex shared Blocker); verified by CoS.*
