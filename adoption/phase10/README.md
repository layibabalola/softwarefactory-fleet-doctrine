project disposition, specification, installation state, or runtime authority. The exact receipt is
`r26-local-candidate-review-receipts.json`.

replacement, provider process, runtime activation, or adoption.

`ACCEPT_INSTALL_CANDIDATE_FOR_SEPARATE_PRIVILEGED_PREVIEW`, exact manifest and tree seals, fresh
suite results, the R7 absence-provenance repair, and the current-token access-denied nonmutation
fingerprint. It authorizes neither the privileged preview nor Apply, installation, task mutation,
runtime activation, or adoption. A separately authorized privileged preview must bind the exact
committed receipt bytes.

This Phase 10 integration is author-conflicted and requires fresh independent review. It does not
push, merge, publish, invoke providers, touch authentication, mutate tasks, gates, leases, packets,
or change the frozen ledger count `ADOPT=0 / DISTINGUISH=5 / STALE=4`.
